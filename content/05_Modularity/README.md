# Python Fundamentals: Modularity

This section will teach you about how to make your code more modular, which helps maintainability and readability.
There are two main basic features of modular code. These consist of functions and importing other Python scripts.
There are also classes, but that is a bigger beast, and will be a whole section for more advanced Python topics.

---

## Phase 5.1: Functions

Functions help make code more concise, especially when it comes to code blocks that will be running many times throughout many differing points of the script. This makes the code smaller and easier to read, keeping logic grouped together with functions.

---

## Phase 5.2: Imports

Imports help make the code more modular by allowing each file to handle specific groups of logic.
For example, you can have a script that handles the main UI loop, which calls a separate
script that contains the backend logic.
