# Python Fundamentals: Collections

Collections help make data processing more feasible, and
quite frankly, a bit easier. You will learn all the
collection types and how you can use them in this Phase.

---

## Phase 4.1: Lists

A list is created with square brackets `[]` and can hold
any object within them. You can add and remove elements,
and there can be more than one of the same element.

---

## Phase 4.2: Tuples

A tuple is like a list but created with regular
parentheses `()`, these values cannot be manipulated and if
you want to update a single element, you will have to 
recreate the tuple with the manipulated value.

---

## Phase 4.3: Sets

Sets are created with curly brackets `{}` full of comma
separated elements or `set()` for an empty one and can only
contain unique elements. These values are able to be
manipulated, and they do not appear in any order.

---

## Phase 4.4: Dictionaries

A dictionary is also created with curly brackets `{}` but
each element is a `key:value` pair instead of a solo object.
These elements can be manipulated, but the keys must be
unique.

---
