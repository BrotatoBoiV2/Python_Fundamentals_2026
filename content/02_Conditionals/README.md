# Python Fundamentals: Conditionals

This Phase covers the basics of conditional branches.
However, to ensure maximum control over the conditionals,
we will first cover variable manipulations - or simply,
Operators.

By the end of this Phase you will be able to write a fully
functional decision algorithm with conditionals, operators
and what you have learned in the previous Phase.

---

## Phase 2.1: Operators

The first concept that will be covered is Operators. These
allow you to manipulate the variables and have more precise
conditional branches. They come in four types;
Arithmetic, Comparison, Membership, and Logical.

You can find a table containing all of the possible
operators below.

### Arithmetic

| Symbol |              Function                  |
| ------ | -------------------------------------- |
|   +    | Add right value to the left.           |
|   -    | Subtract right value from the left.    |
|   *    | Multiply left value by the right.      |
|   /    | Divide left value by the right.        |
|   %    | Remainder of left divided by right.    |
|  //    | Divide left by right, then round down. |
|  **    | Exponent left value by the right.      |

### Comparison

| Symbol |                 Description                    |
| ------ | ---------------------------------------------- |
| ==     | True if left and right values **match**.       |
| !=     | True if left and right values **don't match**. |
| >      | True if left value is **greater** than right.  |
| <      | True if left value is **less than** right.     |
| >=     | True if left is **greater or equal** to right. |
| <=     | True if left is **less or equal** to right.    |

### Logical

| Keyword |                Description                    |
| ------- | --------------------------------------------- |
|   and   | True if **both** left and right are true.     |
|   or    | True if **either** left or right is true.     |
|   not   | **Flips** the boolean of the value.           |

### Membership

| Keyword |                 Description                   |
| ------- | --------------------------------------------- |
|   in    | True if left value is **found in** the right. |
| not in  | True if left value is **not in** the right.   |

## Phase 2.2: Conditionals

Afterwards, you will learn about conditionals and how to
use them to make your program smarter than a simple script.

These are the three keywords that are used.

| Keyword |             Description               |
| ------- | ------------------------------------- |
|   if    | True if both left and right are true. |
|  elif   | True if either left or right is true. |
|  else   | Flips the boolean of the value.       |

You will also learn about `match`/`case`, a more updated
and simpler version of an `if`/`elif`/`else` statement.
