# Start Your Own Coding

This section will walk you through writing and running your own code on your own machine.

---

## Writing The Code

Any text editor would suffice, as long as you can write the file then save it as a `.py` file.
You can use any File Editor, Programming Notepad, or IDE; the only thing that must remain consistent is how you execute the file.

---

## Obtaining The Binary

After writing the code you will want to execute it. You will need to download the interpreter binary by doing the following.

### Linux

**Arch**
```bash
sudo pacman -S python
```

**Ubuntu**
```bash
sudo apt-get install python3
```

### Windows

You can download the `.exe` file by going to [their website](https://www.python.org/downloads/windows/)


## Executing The Code

Afterwards, you can run the command to see your code in action.

```bash
# Arch/Windows
python script.py

# Ubuntu
python3 script.py
```

**Note:** When a script finishes running, the interpreter shuts down completely.
All memory is wiped, meaning your variables and data vanish instantly rather than resetting or saving.
