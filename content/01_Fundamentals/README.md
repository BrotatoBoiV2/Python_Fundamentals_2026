# Python Fundamentals: Foundations

This module teaches foundational concepts for the Python
language such as outputting text to the screen, creating
and using variables, and input handling.

There are only three modules in this phase, which will be
the foundation of any simple script.

---

## Phase 1.1: Output

Output is the most important so it is being covered first.
Every program needs some sort of output so the user can
receive information from it.

---

## Phase 1.2: Variables

Variables make utilizing the output easier by allowing you
to store and manipulate information within them.

---

## Phase 1.3: Input

The final thing to learn is input. This utilizes both the
variables and output to obtain input from the user.

---

## Challenge 1: User Greeter

Using all that was learned, create a script that obtains
information from the user and cleanly displays it.
