# Python Fundamentals: Iterations

In this Phase, you will learn how to utilize loops and
iterations. This will allow you to create scripts that have
main execution loops, allowing them to be fully functional
scripts.

---

## Phase 3.1: While Loops

A while loop runs for as long as its statement returns
True. That means this is perfect for game loops and general
endless loops.

**Note:** Without proper loop control and exiting, you can
create a loop that cannot be ended. Thus, taking up more
system resources.

---

## Phase 3.2: For Loops

A for loop iterates through every item that it finds in the
value it is given. This can help process many different
items of the same type and reduce code complexity.

---

## Phase 3.3: Control Statements

After learning about the basics of the loops, you will then
learn about loop control statements and how they work so
that you can utilize them as much as possible.
